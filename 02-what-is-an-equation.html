What an equation of a line actually means

A line you draw on a grid and an equation like y = 2x + 1 look like different things. They are not. They are two descriptions of the same object. This page is about the link between the picture and the symbols — and it is the idea the whole chapter rests on.

Compare with what I thought

What would it mean to test whether a point belongs to the wire? You would put its coordinates into the equation and see whether the two sides balance.

For (3, 7): 2·3 + 1 = 7, which equals the y. It fits. For (2, 1): 2·2 + 1 = 5, but the point’s y is 1 — it does not fit, so it is off the wire.

That means a formula decides membership for every point. So there must be a precise way to link “the picture” and “the symbols”. This page is that link.

2The mathematics

A line is a rule that points must obey

A line is a locus

A line is a locus (Latin for “place”): the set of all points that satisfy one condition. For y = 2x + 1, the condition is exactly “your y must equal 2·(your x) + 1”. Every point that obeys lives on the line; every point that disobeys does not.

The test

To decide whether (x, y) lies on the line, substitute and check the balance:

for (3, 7):  2(3) + 1 = 7  ✓     for (2, 1):  2(2) + 1 = 5 ≠ 1  ✗
How to say it

We say the point satisfies the equation. The coordinates of a point on the line are just a pair that makes the statement true.

Infinitely many points

Why so many? Because x is free — you may choose it to be anything — but once you do, y is forced by the equation. Pick x, get exactly one y. Since there are infinitely many choices of x, there are infinitely many points on the line.

The two-way promise

Every point on the line satisfies its equation, and every point that satisfies the equation lies on the line. The picture and the symbols are two views of one thing — not two different things.

5Worked examples

Doing it properly, on paper

Try each one yourself first — write it down. Only then open the solution.

Example 1 — does (3, 7) lie on y = 2x + 1? What about (−2, −3)?

For (3, 7): 2(3) + 1 = 7 = y ⇒ yes.

For (−2, −3): 2(−2) + 1 = −4 + 1 = −3 = y ⇒ yes too.

Negative coordinates work the same way; just substitute carefully.

Example 2 — find k so that (4, k) lies on 3x + 2y = 6

Substitute x = 4, y = k:

3(4) + 2k = 6  ⇒  12 + 2k = 6  ⇒  2k = −6  ⇒  k = −3

So the point (4, −3) lies on the line.

Example 3 — which of (0, 3), (3, 0), (1, 3), (−2, 5) lie on y = −x + 3?
  • (0, 3): −0 + 3 = 3 = y ⇒ on
  • (3, 0): −3 + 3 = 0 = y ⇒ on
  • (1, 3): −1 + 3 = 2 ≠ 3 ⇒ off
  • (−2, 5): −(−2) + 3 = 2 + 3 = 5 = y ⇒ on
Example 4 — how many points lie on a line?

Infinitely many. The equation leaves x free. Choose any real x you like — say 0, then 1, then 1.5, then √2, then π — and the equation forces exactly one y each time. There is no last point. The line is the complete, infinite list of all those pairs.

✓ Check yourself before you move on

Four quick questions. Write your answers down first — then open each one.

  1. Does the point (5, 11) lie on y = 2x + 1?
    Answer

    2(5) + 1 = 11 = y, so yes.

  2. Find k so that (2, k) lies on y = −3x + 4.
    Answer

    k = −3(2) + 4 = −6 + 4 = −2.

  3. Why does an equation of a line describe infinitely many points?
    Answer

    Because x is free (any real number) while y is forced by the equation. Each choice of x gives one point, and there are infinitely many choices.

  4. State the two-way promise in one sentence.
    Answer

    Every point on the line satisfies its equation, and every point that satisfies the equation lies on the line.
