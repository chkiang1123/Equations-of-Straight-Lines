Compare with what I thought

She could rearrange it into y = mx + c every single time, like this:

3x − 4y + 12 = 0  ⇒  −4y = −3x − 12  ⇒  y = 34x + 3

That works, but it is work every time — and it hides the slope and intercepts behind a wall of algebra. There should be a way to read the slope and both intercepts straight off the A, B and C that are already sitting there. This page is that formula.

3The mathematics

Reading the line straight off the coefficients

The general form puts everything on one side of the equals sign. No rearranging is needed to recognise it — you just need the three numbers in front of x, y and the constant.

Definition

A straight line written as

Ax + By + C = 0

where A, B and C are numbers and A and B are not both zero. (If both were zero you would have C = 0, which is either always true or never true — not a line at all.)

Slope

Start from the definition and collect the y term on its own, exactly as the engineer did:

  1. Bring everything except the y term to the other side:
    By = −Ax − C
  2. Divide by B (so this needs B ≠ 0):
    y = −ABx − CB
  3. Comparing with y = mx + c, the slope is the coefficient of x:
m = −AB

Intercepts

The x-intercept is where the line crosses the x-axis, so put y = 0. The y-intercept is where it crosses the y-axis, so put x = 0.

x-intercept (set y = 0)

Ax + C = 0  ⇒  x = −CA

y-intercept (set x = 0)

By + C = 0  ⇒  y = −CB
Three numbers, three facts

For Ax + By + C = 0: slope m = −A/B, x-intercept −C/A, y-intercept −C/B. Watch the minus signs — every one of them belongs there.

Why it is called general

The form y = mx + c quietly assumes a finite slope. It cannot write a vertical line. The general form has no such blind spot:

  • If A = 0 the equation becomes By + C = 0, i.e. y = −C/B — a horizontal line. (Exactly the situation from the previous page, where y = k had no slope problem at all.)
  • If B = 0 the equation becomes Ax + C = 0, i.e. x = −C/A — a vertical line. This is the case that y = mx + c simply cannot reach.
Tie-back to the last page

On the horizontal-and-vertical page you learned that a vertical line must be written as x = h because its slope does not exist. The general form swallows that exception for free: just let B = 0. That is the whole reason it earns the name general.

Conventions

To make answers easy to compare, we agree on a tidy standard:

  • Write A, B and C as integers (clear any fractions by multiplying through).
  • Prefer A > 0. If A = 0, prefer B > 0.
  • Never leave A negative if you can fix it by multiplying the whole equation by −1.

Equivalent equations

Multiplying the entire equation by any non-zero number does not change the line — it just changes the labels on the coefficients. So these three all describe one line:

3x − 4y + 12 = 0  ·  6x − 8y + 24 = 0  ·  −3x + 4y − 12 = 0
Two students, two answers, both right

If your equation is a whole-number multiple of the answer key, you are not wrong — you have simply scaled the coefficients. Divide through by the common factor and it will match.

5Worked examples

Doing it properly, on paper

Try each one yourself first — write it down. Only then open the solution.

Example 1 — slope and intercepts of 3x + 4y − 12 = 0

Here A = 3, B = 4, C = −12.

Slope: m = −A/B = −3/4.

x-intercept: −C/A = −(−12)/3 = 12/3 = 4.

y-intercept: −C/B = −(−12)/4 = 12/4 = 3.

Check: the line passes through (4, 0) and (0, 3). Slope = (3 − 0)/(0 − 4) = −3/4 — correct.

Example 2 — write y = 2x − 5 in general form

Bring every term to one side:

y = 2x − 5  ⇒  2x − y − 5 = 0

Now A = 2 (positive, good), B = −1, C = −5. As a check: m = −A/B = −2/(−1) = 2, which matches the original slope.

Example 3 — write x/3 + y/4 = 1 in general form

There is a fraction on every term. Clear them by multiplying the whole equation by 12 (the lowest common multiple of 3 and 4):

12·x3 + 12y4 = 12  ⇒  4x + 3y = 12

Bring the 12 over:

4x + 3y − 12 = 0

Check the intercepts: x-intercept = −(−12)/4 = 3, and y-intercept = −(−12)/3 = 4 — exactly the “a = 3, b = 4” of the intercept form.

Example 4 — for what k does kx + 3y − 6 = 0 have slope 2?

Use the slope formula with A = k, B = 3:

m = −AB = −k3 = 2

So −k/3 = 2  ⇒  −k = 6  ⇒  k = −6.

Check: −(−6)/3 = 6/3 = 2. Correct.

Example 5 — classify 2x + 5 = 0 and 3y − 9 = 0

(a) 2x + 5 = 0. Here A = 2, B = 0. With B = 0 the line is vertical: x = −C/A = −5/2 = −2.5. Its slope does not exist.

(b) 3y − 9 = 0. Here A = 0, B = 3. With A = 0 the line is horizontal: y = −C/B = −(−9)/3 = 3. Its slope is 0.

This is the whole point of the general form: the same machinery handles both, with no special rule.

6The subtle bit

Same line, different outfit

Below is one fixed line, 3x − 4y + 12 = 0. Pick a multiplier. The line must not move — only the equation printed underneath changes.

3x − 4y + 12 = 0

The insight

Multiplying every coefficient by the same non-zero number changes the appearance of the equation but not the line it describes. The graph above never moves. So if your answer is a whole-number multiple of the key, you were right — scale it back to compare.

✓ Check yourself before you move on

Four quick questions. Write your answers down first — then open each one.

  1. Find the slope and both intercepts of 2x − 5y + 10 = 0.
    Answer

    A = 2, B = −5, C = 10. Slope m = −A/B = −2/(−5) = 2/5. x-intercept = −C/A = −10/2 = −5. y-intercept = −C/B = −10/(−5) = 2.

  2. Write y = −3x + 7 in general form.
    Answer

    Bring all terms to one side: 3x + y − 7 = 0. (Here A = 3 > 0, which is the preferred form.)

  3. What kind of line is 4x − 9 = 0, and why?
    Answer

    B = 0, so it is vertical: x = 9/4 = 2.25. The slope does not exist. This is exactly the case y = mx + c cannot express.

  4. Are x − 2y + 4 = 0 and −2x + 4y − 8 = 0 the same line?
    Answer

    Multiply the first by −2: −2x + 4y − 8 = 0. That is exactly the second equation, so yes, the same line — just scaled by −2.
