The two-point form

With two points you never need to be told the slope — you can always work it out. This page turns that simple fact into a reliable method for pinning down any non-vertical line.

If the pace is constant the graph really is straight, so two points fix the steepness — and once you know the steepness you only need one point to place the whole line.

So there must be a method that takes (two points) and hands back the equation. And it must be unique: those two dots allow exactly one line (as long as they are not lined up vertically). This page is that method.

4The mathematics

Two points pin down two unknowns

Why two points are enough

The equation y = mx + c has two unknowns: the slope m and the intercept c. One point gives one condition, which is not enough — infinitely many lines pass through a single point. Two points give two conditions, which pin down the two unknowns. (Except in the vertical case, where no m exists at all.)

Two points → one line

Step 1: compute m = (y₂ − y₁)/(x₂ − x₁). Step 2: drop that m and either point into the point-slope form. That is the whole recipe.

The two-point form

Put the slope straight into the point-slope formula and you get a form that uses only the two points:

y − y₁y₂ − y₁ = x − x₁x₂ − x₁
It is just point-slope in disguise

Replace m in y − y₁ = m(x − x₁) with (y₂ − y₁)/(x₂ − x₁) and you get exactly the two-point form. Nothing new — just a shortcut.

The vertical exception

If x₁ = x₂ the denominator is zero, so there is no two-point form and no point-slope form: the line is simply

x = x₁

The collinearity test

Three points are collinear (on one line) exactly when the slope between each pair is the same. Compute two slopes and compare:

same line  ⇒  y₂ − y₁x₂ − x₁ = y₃ − y₁x₃ − x₁

Watch the vertical case here too: if two pairs share an x-coordinate, compare carefully rather than dividing.

7Worked examples

Doing it properly, on paper

Try each one yourself first — write it down. Only then open the solution.

Example 1 — A(2, 3), B(6, 11)

Slope. m = (11 − 3)/(6 − 2) = 8/4 = 2.

Using A(2, 3). y − 3 = 2(x − 2) ⇒ y = 2x − 1.

y = 2x − 1

Using B instead gives y − 11 = 2(x − 6), which simplifies to the same line.

Example 2 — A(−1, 4), B(3, −4)

Slope. m = (−4 − 4)/(3 − (−1)) = (−8)/4 = −2.

Using A(−1, 4). y − 4 = −2(x + 1) ⇒ y = −2x + 2.

y = −2x + 2
Example 3 — A(−2, 5), B(4, 5): a horizontal line

Slope. m = (5 − 5)/(4 − (−2)) = 0/6 = 0.

Zero slope means flat. Using A: y − 5 = 0·(x + 2), so

y = 5
Example 4 — A(3, 1), B(3, 7): the vertical exception

Slope. x₂ − x₁ = 3 − 3 = 0, so the slope does not exist.

There is no two-point form and no point-slope form. The line is simply

x = 3
Example 5 — are (1, 2), (3, 8), (5, 14) collinear?

slope (1,2)→(3,8) = (8 − 2)/(3 − 1) = 6/2 = 3.

slope (1,2)→(5,14) = (14 − 2)/(5 − 1) = 12/4 = 3.

The slopes are equal, so yes, the three points are collinear.

✓ Check yourself before you move on

Four quick questions. Write your answers down first — then open each one.

  1. Find the equation of the line through (0, −3) and (4, 5).
    Answer

    m = (5 − (−3))/(4 − 0) = 8/4 = 2. Using (0, −3): y + 3 = 2x ⇒ y = 2x − 3.

  2. Find the equation of the line through (1, 2) and (1, 9).
    Answer

    x₂ − x₁ = 0, so the slope does not exist. The line is x = 1.

  3. Are (−2, 0), (0, 3), (2, 6) collinear?
    Answer

    slope A→B = (3 − 0)/(0 − (−2)) = 3/2. slope A→C = (6 − 0)/(2 − (−2)) = 6/4 = 3/2. Equal ⇒ yes, collinear.

  4. A line through (2, 1) and (5, 1): what is special about it?
    Answer

    Slope = 0, so it is horizontal: y = 1.
