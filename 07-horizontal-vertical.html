Horizontal and vertical lines

Two lines refuse to fit the pattern — the flat one and the upright one. Understanding why saves you more marks than almost anything else in this chapter.

2Think

What does it make you think? What relationship might be hiding in what you saw?

Compare with what I thought

On the flat fence every single point has y = 3, whatever its x is. So the whole line is described by the rule “y is always 3” — a sentence about one coordinate only.

On the upright fence every point has x = 5, whatever its y is. So that line is the rule “x is always 5”.

Each fence needs only one number to be pinned down. That is a completely different kind of equation from y = mx + c.

3The mathematics

When one coordinate stops changing

Horizontal: y = k

Every point is (x, k). The y-value is fixed; x can be anything. The slope is 0, because the rise between any two points is zero:

m = 0run = 0

It passes through (0, k) — that is its y-intercept.

Vertical: x = h

Every point is (h, y). The x-value is fixed; y can be anything. The slope does not exist:

m = rise0 — division by zero

The run is zero, so the slope fraction has a zero denominator. That is not “infinity” — it simply does not exist.

Two special equations

A horizontal line is y = k (slope 0). A vertical line is x = h (slope does not exist). Each is a rule about one coordinate only.

"Undefined", not "infinity"

Students often say a vertical line has “infinite slope”. That is the wrong word. You cannot divide by zero, so the slope does not exist — there is no number m that describes it.

Why y = mx + c cannot write a vertical line

The form y = mx + c always produces a finite slope m. A vertical line has no such number, so there is no value of m that will draw it. It must be written separately as x = h.

Parallel to the axes; the axes themselves

A horizontal line is parallel to the x-axis; a vertical line is parallel to the y-axis. The two special cases y = 0 and x = 0 are the axes themselves.

A preview of the general form

Both lines do fit Ax + By + C = 0. The line y = k is 0·x + 1·y − k = 0 (so A = 0). The line x = h is 1·x + 0·y − h = 0 (so B = 0). That is exactly why the general form, next page, is called general.

From the figure:

y = k ⇒ 0x + 1y − k = 0

x = h ⇒ 1x + 0y − h = 0

When A = 0 the line is horizontal; when B = 0 it is vertical. Watch for that on the next page.

5Worked examples

Doing it properly, on paper

Try each one yourself first — write it down. Only then open the solution.

Example 1 — horizontal line through (4, −7)

All points on a horizontal line share the same y. The given point has y = −7, so:

y = −7

Its slope is 0.

Example 2 — vertical line through (4, −7)

All points on a vertical line share the same x. The given point has x = 4, so:

x = 4

Its slope does not exist (run is zero).

Example 3 — through (2, 5) and (9, 5)

Both points have the same y-value (5), so the line is horizontal:

y = 5

Slope = 0. (If the y-values had differed but the x-values were equal, it would have been vertical instead.)

Example 4 — through (2, 5) and (2, −3)

Both points have the same x-value (2), so the line is vertical:

x = 2

Slope does not exist.

Example 5 — the lines through the origin

The horizontal line through (0, 0) is y = 0 (the x-axis). The vertical line through (0, 0) is x = 0 (the y-axis). Together they are the two coordinate axes themselves.

6Watch out

Four ways to lose marks

MistakeWhat goes wrongDo this instead
Writing x = 3 for a horizontal lineThe coordinate that is fixed is the wrong oneHorizontal means y is fixed: write y = 3
"The vertical line's slope is infinity"Infinity is not a number and not the right wordWrite does not exist
Confusing slope 0 with "no slope"They are opposites, not the sameSlope 0 = flat horizontal line; "no slope" = vertical line

✓ Check yourself before you move on

Four quick questions. Write your answers down first — then open each one.

  1. Write the equation of the horizontal line through (−2, 8).
    Answer
    y = 8

    Slope 0.

  2. Write the equation of the vertical line through (−2, 8).
    Answer
    x = −2

    Slope does not exist.

  3. A line passes through (1, 4) and (1, −3). What is its equation and slope?
    Answer

    Same x-value, so it is vertical: x = 1. Slope does not exist.

  4. Can the line x = 4 be written in the form y = mx + c? Explain.
    Answer

    No. y = mx + c always has a finite slope m, but x = 4 is vertical and has no slope. It can only be written directly as x = 4 (or as 1x + 0y − 4 = 0 in general form).
