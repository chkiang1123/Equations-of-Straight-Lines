2Think

What does it make you think? What relationship might be hiding in what you saw?

Compare with what I thought

The starting value is where distance = 0 — that is the point where the line meets the vertical axis. That number must be the intercept.

The rate of climb is the slope: how much the fare rises for each kilometre. So the two numbers in the equation — the start and the rate — are both visible in the picture.

That means there really must be a form of the equation made of exactly those two numbers.

3The mathematics

The form that names its own numbers

The slope-intercept form writes a line as:

y = mx + c

(Some books write y = mx + b — the letter changes, the idea does not.) Here m is the slope and c is the y-intercept: the value of y when x = 0.

Why c is the intercept

Put x = 0 into y = mx + c:

y = m(0) + c = 0 + c = c

So the line passes through (0, c). The number c literally is where the line meets the vertical axis.

What each sign of m looks like

  • m > 0 — the line climbs to the right (the taxi fare).
  • m < 0 — the line falls to the right.
  • m = 0 — the line is horizontal: y = c, a constant.

And c = 0 means the line passes through the origin: y = mx.

Converting in

From point-slope (page 3): expand y − y₁ = m(x − x₁) and collect the constant term — that constant is c.

From general form Ax + By + C = 0, solve for y:

By = −Ax − C  ⇒  y = −ABx − CB

So m = −A/B and c = −C/B.

Converting out

To return to general form, bring everything to one side: y = mx + c ⇒ mx − y + c = 0.

Read the graph as a sentence

Start at c on the vertical axis, then rise m for every 1 across. The rise-over-run triangle makes the slope visible.

6Worked examples

Doing it properly, on paper

Try each one yourself first — write it down. Only then open the solution.

Example 1 — slope 3, y-intercept −2

Step 1. m = 3, c = −2. Substitute:

y = 3x − 2

Step 2. To general form, bring all terms to one side: 3x − y − 2 = 0.

3x − y − 2 = 0
Example 2 — find m and c for 2x + 3y − 6 = 0

Solve for y:

3y = −2x + 6  ⇒  y = −23x + 2

So m = −2/3 and c = 2.

Example 3 — through (0, 4) and (3, −2)

The point (0, 4) is on the y-axis, so c = 4. Slope:

m = −2 − 43 − 0 = −63 = −2

Therefore y = −2x + 4.

Example 4 — crosses the y-axis at 3 and passes through (2, 1)

c = 3. Slope using the two points (0, 3) and (2, 1):

m = 1 − 32 − 0 = −22 = −1

So y = −x + 3.

✓ Check yourself before you move on

Four quick questions. Write your answers down first — then open each one.

  1. Write y = 4x − 7 in general form.
    Answer

    Bring all terms to one side: 4x − y − 7 = 0.

  2. For 5x − 2y = 8, what are m and c?
    Answer

    2y = 5x − 8, so y = (5/2)x − 4. Thus m = 5/2, c = −4.

  3. A line through (0, −1) and (2, 5): write y = mx + c.
    Answer

    c = −1. m = (5 − (−1)) / (2 − 0) = 6/2 = 3. So y = 3x − 1.

  4. What does y = −x + 3 look like on a graph?
    Answer

    It crosses the y-axis at 3 and falls one unit for every unit to the right (slope −1), so it makes a line slanting down to the right.
